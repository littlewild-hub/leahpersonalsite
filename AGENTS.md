# Agent Instructions

For any frontend, UX, visual-design, responsive, accessibility, interaction, navigation, typography, layout, or UI-copy work in this repository, read and follow `DESIGN_OPERATING_LAYER.md` before editing.

The design operating layer combines UI/UX Pro Max for design-system and UX intelligence with Impeccable for critique, audit, refinement, and shipping quality.

Key constraints:

- The user's explicit brief wins.
- Inspect the existing interface and visual evidence before changing it.
- Distinguish refinement from redesign; never silently convert one into the other.
- Preserve factual copy, claims, behavior, and content unless the user explicitly asks to change them.
- Use the repository's actual stack: Next.js 15 + React 19.
- Do not genericize the site into familiar AI/SaaS visual defaults.
- Treat accessibility, responsive behavior, and keyboard interaction as shipping requirements.
- Use bounded QA: inspect, consolidate fixes, confirm, then stop rather than polishing indefinitely.

Upstream source versions and the combined workflow are recorded in `DESIGN_OPERATING_LAYER.md`.
